# maimai_live-
一个用于舞萌的直播辅助工具（可国服或日服[最新到circle版本，不包含magical]）

本工具基于[落雪咖啡屋maimai DX 查分器的api获取了部分歌曲信息以及别名](https://maimai.lxns.net/)、[arcade-songs的全部歌曲数据](https://arcade-songs.zetaraku.dev/maimai)，以及导航工具[DXrating](https://dxrating.net/search)

其中开发者在电脑当中安装了python3.13以及nodejs最新版本，内容数据更新可以自行从以上网站获取

其中anname_list是别名库对应了[落雪别名库](https://maimai.lxns.net//api/v0/maimai/alias/list)可通过ctrl+S直接保存，需自行重命名
hot_songs是点歌最多的歌曲排行榜
当用户想要使用可以直接双击启动' start.bat '
使用之后可按照提供的链接映射到直播工具当中的浏览器模块
